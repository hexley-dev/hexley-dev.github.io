07 — Lessons Learned

What we learned
the hard way.

Lesson 01
One GPU process at a time
The published v1/v2 image generation used Z-Image-Turbo on local MPS. Two parallel runs crashed the GPU. The script that deleted 61 images before confirming torch worked was the costliest mistake. Current experimental work uses FLUX.2-dev (NVFP4) on DGX Spark.
Lesson 02
Content before pixels
Lock the script with Editor + Red Team review before generating a single image. Content changes after image gen means throwing away expensive work.
Lesson 03
Seed-then-prompt escalation
Try 2-3 seeds. If all fail, the problem is the prompt, not the randomness. Mutate the prompt.
Lesson 04
Monospace everywhere in SVGs
Cursive and proportional fonts in SVG diagrams cause cramming and overlap. JetBrains Mono for ALL SVG text — no exceptions.
Lesson 05
Verify before walking away
"Running" ≠ "working." After launching any background batch, confirm the first 1-2 outputs exist and are valid.
Lesson 06
Photo-real humans → likeness drift
FLUX.2-dev generates convincing photo-real humans, but they drift from actual historical figures. Stylized illustration gives artistic license. Photo-real works beautifully for robots and environments.
Lesson 07
Never bulk-delete before confirming replacements work
The session that deleted 61 images before verifying torch was functional was the costliest mistake. Use per-item pattern: backup → generate → verify → next.
Lesson 08
Fix patterns, not instances
One agent fixing all occurrences of an error class prevents 20-spawn proofreading loops. Sweep the whole file, not just the reported line.
Lesson 09
Save state obsessively
Update MEMORY.md every 3 interactions. The orchestrator session is a single point of failure — when it crashes, all in-flight state is lost.
Lesson 10
Rules must live in files, not conversation
If a mistake can happen once, it can happen again. Codify it immediately in CLAUDE.md, art_direction.md, or agent prompts.
