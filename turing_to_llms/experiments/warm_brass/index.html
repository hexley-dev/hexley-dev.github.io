Can a Machine Think?

It sounds like the kind of question a kid asks at 2 AM. The kind adults smile at and say, "That's very interesting, dear."
But in 1928, one of the most famous mathematicians alive asked this question seriously. And he expected the answer to be yes.
Spectacularly, beautifully, world-changingly wrong.

The story of how we found that out is the story of how computing was born. Not in a lab. Not in a factory. In the mind of a mathematician who liked to run long distances and think about impossible things.
His name was Alan Turing. And he was only 23 years old.
Page 2

The Long-Distance Thinker

King's College, Cambridge. 1936.

Alan Turing was 23, shy, and brilliant. He stammered when he talked. He ran long distances — not to compete, but to think.
ALAN TURING
Born: June 23, 1912, London
Age in 1936: 23

"Sometimes it is the people no one imagines anything of who do the things that no one can imagine."
That year, Max Newman lectured on the foundations of mathematics. One question seized Turing's imagination — a challenge posed by David Hilbert.
The question was called the Entscheidungsproblem. And it would change everything.
Page 3

The Decision Problem

Bologna, Italy. 1928.

David Hilbert issued a grand challenge: a universal mechanical procedure — an algorithm that could settle any mathematical question.
Hilbert's dream: feed any mathematical statement into a machine and get back TRUE or FALSE. Pure mechanical certainty.
But in 1931, a quiet logician in Vienna had already begun pulling at the threads.
Kurt Gödel showed that any consistent formal system powerful enough to describe arithmetic must contain truths it cannot prove. Hilbert's program was already cracking.
Nearly a century earlier, Ada Lovelace had glimpsed the idea of a programmable machine — writing what many consider the first algorithm in 1843.
Turing's stroke of genius: instead of attacking the problem with logic, he imagined the simplest possible machine...

The Simplest Possible Machine

Turing asked: What does it actually mean to "compute" something? Not with a fancy machine — with the simplest possible one.
He called it an a-machine — we call it a Turing Machine. It needs only:
1. An infinite tape divided into squares, each holding a symbol.
But can this absurdly simple machine actually compute anything? Let's watch it work...
Page 5

Watch It Compute

In unary notation: 1 = one mark, 2 = two marks. To add 1+1, the tape reads 1 0 1 — one mark, separator, one mark. The machine merges them by replacing the separator, then erases one extra mark to get the correct count: 1 1 (two marks = 2).
The big idea: This absurdly simple machine can be programmed. Change the rules, compute something different. That's the foundation everything else is built on.

A Machine That Can Be Any Machine

Each task needs its own machine. Turing's question: what if one machine could simulate any other?
Turing's leap: the rule table itself could be written on the tape. A Universal Turing Machine takes a description of any machine M + input for M, then perfectly simulates M.
That's exactly what a modern computer does. Hardware = Universal Machine. Software = machine descriptions. Turing invented software — in 1936, on paper.
A machine that can do anything. But are there things even it can't do?
Page 7

The Thing That Cannot Be Done

Can you always determine whether a program will halt or run forever?
Turing proved this detector cannot exist. Assume detector H exists. Build program D that does the opposite of H's prediction. Run D on itself. If H says halt, D loops. If H says loop, D halts. Contradiction.
The big idea: Some problems are provably unsolvable. Not because we're not smart enough — mathematics itself has boundaries.
Turing wasn't the first to find limits. A few years earlier, in a Vienna coffee house...
Page 8

The Man Who Broke Mathematics

Vienna, 1931. Kurt Gödel — quiet, intense, 25 — published two theorems that shattered the foundations of mathematics.
First Incompleteness: Any consistent system powerful enough to describe arithmetic contains truths that are true but unprovable.

Second Incompleteness: Such a system cannot prove its own consistency.
Imagine an infinite library of mathematical truths. Gödel showed there will always be glowing gaps — truths that exist but can never be catalogued.
Gödel showed truth outruns proof. Turing showed computation has boundaries. Together: formal systems have permanent, provable limits. But mathematics as a living discipline is far richer than any formal system.
Meanwhile, across the Atlantic, someone else reached the same conclusion by a completely different path...
Page 9

The Thesis That Defines Computing

1936. Two mathematicians, two continents, same problem. Turing built his imaginary machine. Alonzo Church invented lambda calculus. Different methods. Same answer.
The Church-Turing Thesis: any function computable by a reasonable mechanical process is computable by a Turing Machine. Not a theorem — a thesis. In 90 years, no counterexample.
Quantum computers may solve certain problems exponentially faster, but cannot solve undecidable problems. Speed differs. Capability does not.
In 1936, this was all pure thought. But the world was about to need real machines — desperately.
Page 10

Now Build It

Princeton, 1937. Turing completed his PhD under Church. "On Computable Numbers" was published. But outside the windows, the world was darkening.
• Konrad Zuse built the Z3 (1941) — first programmable computer
• Colossus cracked Nazi codes at Bletchley Park — with Turing
• ENIAC (1945) — 30 tons, 17,468 vacuum tubes
• Von Neumann read Turing's paper and saw a blueprint
Every computer ever built is a physical realization of Turing's imaginary machine. He didn't predict computing. He defined it.
